      Context Guardian

      Keeps coding agents inside your app's map

      Before a coding agent edits, Context Guardian tells it which features, rules and checks the task touches. When it finishes, it compares the change with that map and reports what the agent missed.

      View on GitHub
      HighlightsScreenshots

      Highlights

      • Maps your features and rules

        Features, invariants and checks in one place

      • Checks every change

        Finds code that imports what the agent changed

      • Tells the agent what it missed

        An iOS change left out of Android, or a weakened rule

      • Works with your agents

        Claude Code, Codex, Gemini CLI, Cursor, Copilot

      • Local and private

        No model calls, no network, no telemetry

      • Agents run only safe commands

        Others need your approval; publish and push are never allowed
